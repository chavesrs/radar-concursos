# Radar de concursos — Contabilidade Pública, AFO e Auditoria

Lista de concursos públicos (federais, estaduais e municipais) para Contador e cargos cujo edital cobra Contabilidade Pública, AFO/Direito Financeiro ou Auditoria Governamental.

- `concursos.json`: a lista, atualizada todos os dias de manhã por uma tarefa agendada do Claude.
- Exibida em https://www.contas.cnt.br/concursos/

Confira sempre o edital oficial antes de se inscrever.
